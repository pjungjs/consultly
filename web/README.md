# Consultly web (Next.js)

The Consultly website: catalogue, consultant profiles and booking, My bookings, consultant dashboard, profile, PDF briefs and the Help bubble. Runs on port 3000 and talks only to the API.

See the [project README](../README.md) for setup. Common commands:

```bash
npm run dev    # http://localhost:3000
npm test       # unit tests for the pure helpers in lib/
npm run lint
```
